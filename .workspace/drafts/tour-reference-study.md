## 2. 🔴 우리와 대조

### 2.1 우리가 «이미» 앞선 것 — 하나. 그리고 그게 오늘의 문제였다

> **읽은 여섯 개 전부, 팝오버 회피는 「뷰포트 경계」 기준입니다.**
> driver.js 는 「화면 밖으로 나가면 뒤집고」, Reactour 는 「스크롤해서 보이게 하고」, ReactDriver 는 「대상 둘레에 여백을 주는」 것입니다.
> 🔴 **「옆에 있는 «읽어야 할 글자»를 가리지 않게 한다」를 하는 곳은 한 곳도 없었습니다.**

우리가 오늘 겪은 것이 정확히 그것이고(9단계 중 8단계에서 글자를 덮음), 우리가 만든 **런타임 겹침 회피**(후보 자리를 실측해 덜 가리는 쪽을 고름)는 이 축에서 **참고 자료들보다 앞서 있습니다** — 실측 **−36.8%**(714자 → 451자).

⚠ **다만 그들이 못 한 게 아니라 «안 한» 것일 수 있습니다** — 대부분의 제품은 투어 중 뒤 배경을 어둡게 덮으므로 「가려진 글자」가 애초에 문제가 안 됩니다. **우리는 배경을 살려 두는 설계**라 이 문제가 생겼고, 그래서 답도 우리가 만들어야 했습니다.

### 2.2 🔴 우리가 부족한 것

| # | 부족한 것 | 근거 | 심각도 |
|---|---|---|---|
| **A** | **접근성을 한 번도 안 쟀다** — 키보드 완주 · focus trap · `aria-live` · Esc · 종료 후 포커스 복귀 | tour-kit 은 **WCAG 2.1 AA** 를 명시하고, joyride 는 focus trap 을 전면에 둔다. **우리는 「된다/안 된다」조차 모른다** | 🔴 **높음** (지금 실측 중) |
| **B** | **진행 조건이 코드에 흩어져 있다** | 우리는 `tour-next` / `tour-goto` / `tour-await-click` **세 갈래**가 스텝마다 다르게 붙어 있어, **「next 만 보면 9단계 중 3단계에서 멈춘다」**는 함정이 실제로 났다. ReactDriver 는 그것을 **`advanceOn` / `canAdvance` 두 선언**으로 묶는다 | 🔴 **높음** |
| **C** | **스포트라이트·말풍선 여백이 코드 상수** | 그들은 `stagePadding` 처럼 **값으로 노출**해 조정과 측정이 쉽다. 우리는 고치려면 코드를 읽어야 한다 | 🟡 중간 |
| **D** | **수명주기 훅이 없다** | `onHighlighted` 같은 지점이 있으면 **검증 그물이 「지금 몇 단계인지」를 추측하지 않아도 된다.** 오늘 검증이 진행 수단 3종을 손으로 다뤄야 했던 이유 | 🟡 중간 |
| **E** | **말풍선을 «안 띄우는» 선택지가 없다** | ReactDriver 의 `popoverless`. 가릴 것이 많은 단계는 **강조만 하고 말은 아래에 두는** 도피가 가능하다 | 🟢 낮음(대안) |

## 3. 적용안 — 우선순위

### 🔴 1순위: 접근성 (A)
지금 검증 좌석이 5축을 실측 중입니다(키보드 완주 · 포커스 가둠 · ARIA · Esc · 종료 후 복귀).
🔴 **설계 판정 하나를 이미 냈습니다** — **focus trap 의 경계는 「말풍선」이 아니라 「말풍선 ∪ 현재 하이라이트 대상」**이어야 합니다. 우리 step6 은 **뒤 배경의 칩을 직접 눌러야** 넘어가는데, 완전한 trap 이면 **키보드 사용자는 그 자리에서 갇힙니다.** 참고 자료들이 「스포트라이트 안은 클릭 가능」으로 푸는 것과 같은 형태입니다.

### 🔴 2순위: 진행 조건의 선언화 (B)
스텝 정의에 **「무엇을 누르면 진행」·「무슨 조건이면 진행 가능」**을 선언으로 두고, 코드 분기를 없앱니다.
· **얻는 것**: 검증 그물이 **선언만 읽으면** 9단계를 다 돌 수 있습니다(오늘처럼 세 경로를 손으로 알아낼 필요가 없습니다). 스텝을 추가할 때 함정이 재생산되지 않습니다.
· **범위**: 규격서(`t6-5-guided-tour-spec.md`) 개정 + 투어 컴포넌트 리팩터. 🔴 **재가 필요**(구조 변경).

### 🟡 3순위: 여백 토큰화 (C) · 수명주기 훅 (D)
둘 다 작고, **측정을 쉽게 만드는** 축입니다. 2순위와 같은 PR 에 묶으면 비용이 거의 안 늡니다.
