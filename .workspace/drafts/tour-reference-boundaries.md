## 5. 🔴 제가 확인하지 못한 것

- **Reactour · tour-kit · react-driver · UserTourKit · Guide.js 의 라이선스** — 넷은 아직 안 읽었고 Guide.js 는 **403 으로 접근 자체가 막혔습니다.**
- **특허** — UI 상호작용 특허는 제 확인 범위 밖입니다. 다만 **우리가 코드를 안 가져오고 널리 쓰이는 관행(포커스 트랩·오토 플립)만 쓰는 한** 실질 위험은 낮다고 봅니다. **이것은 소견(E3)이지 확인이 아닙니다.**
- **상용 서비스(UserTourKit)의 이용 약관** — 화면을 참고하는 행위에 제한을 두는 조항이 있는지 안 읽었습니다.
