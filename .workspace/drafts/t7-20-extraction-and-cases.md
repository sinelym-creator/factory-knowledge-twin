## 2. 🔴 행위 불변 — «새 프로세스» 두 벌에서 12칸 전수 대조

투어 초대 → 시작 → 다음×2 → 저장값 → **새로고침 재개** → 건너뛰기 → 「나중에」 → 저장값 → 「?」 재진입 → 구버전 `skipped` 저장값 주입 후 재방문.

| 칸 | 값(전·후 동일) |
|---|---|
| 1단계 제목 | 「둘러보기를 시작합니다」 |
| 3단계 제목 | 「조사를 시작하면 에이전트가 5단계」 |
| 진행 중 저장값 | `{"v":1,"status":"running","step":2}` |
| **새로고침 뒤** | 같은 3단계로 **이어서 열림** |
| 「나중에」 뒤 저장값 | `{"v":1,"status":"dismissed","step":2}` · 말풍선 사라짐 |
| 「?」 재진입 | 3단계로 **이어서** · `status` 다시 `running` |
| 구버전 `skipped`+step 99 | 양쪽 다 투어 안 열림 · 초대 1 · 저장값 그대로 |

🔴 **다른 칸 = 0 / 12.** 추출은 결정도 저장값도 바꾸지 않았다.
