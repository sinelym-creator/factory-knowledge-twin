## 4. 이 문서가 «모르는» 것

- 🔴 **2절에 남은 2행** — 화면으로 안 열어 봤다. 「보일 것이다」가 아니라 **미확인**이다(1-B 로 올라간 3행만 확정).
- 🔴 **내 1차 문면이 한 군데 틀렸다** — 2절에 「둘러보기 닫기」를 「'잠시 멈춤'과 '다시 보지 않기'가 갈린다」로 적었으나, 실제 낱말은 **「나중에」**이고 **1단계 화면에는 안 보인다**(「건너뛰기」를 눌러야 나온다). 커밋 메시지에서 옮겨 적은 낱말은 **화면의 낱말이 아니었다.**
- 공개 배포물의 **둘러보기·모달·설정 축**은 대조 자체를 못 했다(서버 HTML 밖).
- 두 무대의 데이터 원천이 다르다: 시연 무대는 로컬 가짜 API(`:8101`), 공개 배포물은 배포 API. **수치가 다르면 그건 이 표의 대상이 아니다.**
