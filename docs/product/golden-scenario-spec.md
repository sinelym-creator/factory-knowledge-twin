# Golden Scenario Spec — GS-01 «스핀들 진동 이상 조사»

> 🔴 본 시나리오는 동결 후 **회귀 최우선 복구 대상**(baseline §33.1)이다. 엔티티 ID는 자리표시자이며 T0-6(온톨로지 스펙) 동결 시 실제 ID 체계로 1:1 바인딩한다(«바인딩 표» 절에 기록).

## 1. 시나리오 한 줄

CNC 밀링 설비의 스핀들 진동 RMS가 임계 초과 → AI 조사 → 원인 후보 «스핀들 베어링 마모»(유력)·«공구 불균형» → 근거 인용 → 베어링 점검·교체 작업지시 초안 → 승인.

## 2. 무대 (seed 데이터 요구 — T0-6·Phase 1 입력)

| 요소 | 자리표시자 | 요구 |
|---|---|---|
| 공장/라인 | PLANT-A / LINE-2 | 라인 2~3개 중 하나에 이상 집중 |
| 설비 | EQ-CNC-204 (CNC 밀링) | 모델·설치일·담당 속성 |
| 센서 | SEN-204-VIB (진동 RMS) · SEN-204-TEMP · SEN-204-CUR | 진동 = 3주 완만 상승 + 최근 24h 급등 파형 · 온도 동반 상승(약) |
| 알람 | ALM-2041 «진동 임계 초과» | threshold·발생 시각 |
| 고장모드 | FM-BRG-WEAR «스핀들 베어링 마모» · FM-TOOL-IMB «공구 불균형» | 설비 모델↔고장모드 관계 |
| 정비 이력 | WO-HIST-0087(18개월 전 동일 설비 베어링 교체) · 유사 설비 EQ-CNC-207 이력 1건 | «유사 장애» 검색의 근거 |
| SOP | SOP-BRG-INSP-v2 «스핀들 베어링 점검·교체» | 절차 단계·필요 부품 |
| 안전 규정 | SAF-LOTO-01 «정비 전 잠금·표시(LOTO)» | 작업지시에 의무 포함될 조항 |
| 문서 | 설비 매뉴얼 MAN-CNC-2xx(진동 진단 절) | 인용 강조 대상 원문 문장 |

## 3. 단계 대본 (단계별 기대 evidence — 회귀 판정 기준)

| # | 단계 | 행위자 | 기대 결과 | 기대 evidence(유형) |
|---|---|---|---|---|
| S1 | 알람 발생·선택 | 방문자 | Overview에서 EQ-CNC-204 이상 표시 → 클릭 | ALM-2041 · SEN-204-VIB 추세 chart(급등 파형) |
| S2 | 조사 개시 | Agent | 조사 계획 선언(조사 단계 목록 스트리밍) | agent event: plan 노드 |
| S3 | 구조화 조회 | Agent | 알람·센서 통계·최근 정비 이력 요약 | SQL 결과: ALM-2041·WO-HIST-0087 |
| S4 | 유사 사례 검색 | Agent | 유사 장애·매뉴얼 진동 진단 절 인용 | vector hit: MAN-CNC-2xx 해당 문장 · WO-HIST 유사건 |
| S5 | 그래프 추적 | Agent | EQ-CNC-204 →(모델)→ FM-BRG-WEAR →(절차)→ SOP-BRG-INSP-v2 →(의무)→ SAF-LOTO-01 경로 | graph path 3~4 hop 시각화 |
| S6 | 원인 종합 | Agent | 후보 2개 + 신뢰 순위 + 각 근거 묶음 | 후보별 evidence ID 목록(S3~S5의 실체) |
| S7 | 작업지시 초안 | Agent | 베어링 점검·교체 초안(부품·절차·LOTO 안전 조치 포함) | SOP-BRG-INSP-v2·SAF-LOTO-01 인용 |
| S8 | 편집·승인 | 방문자 | 초안 수정(예: 일정 변경) → 승인 → 상태 전이·이력 기록 | 승인 audit 기록 |
| S9 | 리셋 | 방문자 | one-click reset → 초기 상태 · 타 세션 무영향 | session 격리 확인 |

- 🔴 **회귀 판정**: S1~S9 각 단계의 기대 evidence «유형»이 하나라도 비면 FAIL. 후보 순위(유력 = FM-BRG-WEAR)가 바뀌면 FAIL.
- Unanswerable 가드(평가 연동): 시나리오 밖 질의(예: 「EQ-CNC-999 상태는?」)에 «근거 없음»을 답해야 PASS — T0-8 문항과 연결.

## 4. 3분 데모 스크립트 (product-brief §5와 동일 축 — 발화 대본)

0:00 「synthetic 공장입니다. 라인 2의 CNC 밀링에 진동 알람이 떠 있습니다」 → 0:20 알람 클릭, 3주 추세 급등 확인 → 0:50 「조사를 시작하면 에이전트가 계획을 세우고 DB·문서·그래프를 차례로 뒤집니다 — 지금 단계가 실시간으로 흐릅니다」 → 1:40 「원인 후보마다 근거가 붙습니다. 그래프 경로와 매뉴얼 원문 인용을 직접 확인할 수 있고, 검색 전략별로 결과가 어떻게 다른지 비교합니다」 → 2:20 「작업지시 초안을 사람이 고치고 승인합니다 — AI는 확정하지 않습니다」 → 2:50 「리셋하면 처음으로 — 노트북이 꺼져 있어도 이 전체가 replay로 돕니다」.
