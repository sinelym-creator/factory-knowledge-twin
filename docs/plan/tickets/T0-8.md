# T0-8 — 평가 질문 초안

## 목표
retrieval·agent 품질을 잴 평가 질문 세트 초안 — D3 검색 3전략 비교와 배포 후 벤치마크의 씨앗.

## 산출물
- `benchmarks/datasets/eval-questions-draft.md` — 8~10문. 유형 4종 필수 포함:
  - Direct(단일 근거 사실 질의) · Multi-hop(그래프 2단+ 추적) · Safety(안전 규정 결합) · Unanswerable(근거 부재 — 「모른다」가 정답).
- 문항별: 질문 · 유형 · 기대 답 요지 · 기대 evidence(어떤 문서/그래프 경로가 근거여야 하는지) · acceptance threshold 초안(무엇이면 PASS인지 판정 가능하게).

## AC (판정 = 오케)
- [ ] 8~10문 · 4유형 각 2문 이상.
- [ ] 전 문항에 기대 evidence가 «데이터 스펙(T0-6) 위 실체»로 적혀 있다(추상 표현 = FAIL).
- [ ] Unanswerable 문항에 «환각 시 오답 패턴» 예시 1개씩.
- [ ] threshold가 Target/Actual 분리 서식으로 초안돼 있다(수치는 «잠정 목표» 표기 — 측정-주장 경계).

## 컨텍스트
- `docs/baseline/poc-baseline-v0.2.md`에서 `평가|evaluation|benchmark` 검색 → 해당 절만. UC-01(164~) · T0-6 스펙(도착 후 교차 — 초안은 도착 전 착수 가능).

## 태스크
1. baseline 평가 절 발췌 → 2. 유형별 문항 초안 → 3. 기대 evidence 매핑(T0-6 교차) → 4. threshold 초안 → 5. «보고» 회신.
