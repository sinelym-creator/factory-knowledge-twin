# T2-3 — LangGraph 조사 워크플로우

## 목표

조사 실행의 5단계 plan(`structured → vector → graph → synthesize → draft_work_order`)을 LangGraph로 세우고, GS-01 대본에 결속된 실행 실물 + **step 이벤트 스트림(agent-events 스키마)**을 낸다. 🔴 **Claude 구독 공개 API 노출 금지(§15.2)** — synthesize의 LLM 호출은 «로컬 실행 경계» 안에서만이다.

## 단계 게이트 (순서 고정)

1. **계약·스키마 실독 보고 선행** — agent-events 스키마(`packages/contracts/`) + runs 표면(`POST /scenarios/{id}/runs` · `GET /runs/{runId}` · `/events` · `POST /runs/{runId}/stop` · `WS /ws/runs/{runId}`) 실독 → 🔴 «이 티켓이 해제하는 라우트 범위»를 보고로 올리고 판정 받는다(runs 표면 전부인지, WS는 이월인지 — 오케 판정 사안). `/graph/paths` 귀속 재판정(Q-18)도 이 게이트에서.
2. **LLM 없는 3단계 먼저** — structured·vector·graph 노드는 T2-1 retrieval 경로 재사용(새 검색 경로 금지 — 있으면 회부). 단계별 이벤트 산출이 완료 증거.
3. **synthesize = Claude 로컬 호출 경계** — 🔴 자격 증명이 서버 표면·응답·로그·이벤트에 노출 0 · 공개 API 경로에서 synthesize 트리거가 «구독 프록시»가 되지 않는 구조(운영자 로컬 실행/사전 녹화 축과의 관계를 게이트 1 보고에 소견으로) · live 불가 시 replay 강등은 계약 성문분.
4. **draft_work_order** — 초안 «생성»까지만(승인·CRUD 표면 = T2-5). R12 REQUIRES(안전 조치) 필드가 초안에 실리는 것까지 — 서버 강제는 T2-5.
5. **GS-01 대본 결속 실행 실물** — 대본 단계↔step 이벤트 대응 + 근거 evidenceId가 T2-2 표면으로 해석 가능함을 실증. 🔴 Q-9 결속: 착지 시 실물 rank2 후보를 보고(화면·대본 재바인딩은 오케 패스).
