# T2-6 — Phase 2 독립 검증 (통합)

## 목표

baseline §21 Phase 2 완료 증거 4종을 «한 번의 통합 사이클»로 실증한다 — 티켓별 검증(T2-1~T2-5 각 PASS)은 «부분의 참»이고, 본 티켓은 «전체가 함께 참인가»다: GS-01 integration(조사 완주→근거 열람→WO 승인 왕복) · 3전략 동일 질문 실측 · evidence↔원문 일치 · 계약 준수 전 표면.

## 단계 게이트 (초안 — 발주 시 확정)

1. **정본 대조 선행** — baseline §21 「Phase 2 완료 증거 4종」 원문을 실독하고 «증거↔실측 축» 대응표를 보고로 올린다(축이 증거를 전부 덮는지 — AC가 정본보다 짧은 자리를 먼저 찾는다 · 6대 계보).
2. **E2E 통합 시나리오** — GS-01 대본 S1~S9를 «한 세션»으로 완주: 시나리오 선택 → 조사 실행(live) → 이벤트/되감기 → 근거 열람(/evidence·/documents 왕복) → 그래프 경로(byRun) → WO 초안 편집(R12 대조군 포함) → 승인 → replay 재생. 🔴 각 단계 산출이 다음 단계의 입력으로 실재하는지가 통합의 정의다(단계별 PASS의 나열이 아니다).
3. **회귀 전수** — 전 그물(15종 + tests/api 전 자산) 1회 · 계약 표면 전 라우트 대조(해제분 = 계수 일치 · 잔여 501 = 사유 코드 참).
4. **판정문** — T1-9 방식(범위 한정 · 못 잰 열 명시 — live 게이트 열 = 데모 리허설 결속 유지) → 🔴 오케 통합 판정 + 운영자 직보(Phase 게이트 — §32.1 「독립 검증 PASS + E2E 통합 PASS만 Release 범위」).
