# T1-8 — FastAPI async skeleton

## 목표

S2 잔여 골격 — 계약 v0.1이 약속한 API 표면을 «완전 비동기 골격»으로 세운다. 도메인 기능 0 · 구조의 확장 경계 보존(system-architecture §7).

## 산출물

- `services/ai-api/`: 계약 v0.1(`packages/contracts/` — REST 문서·이벤트 스키마 · 🔴 동결본) 표면의 라우터 골격 — 실구현 0, 자리표시자 응답 + 계약 형상 준수.
- 완전 비동기(§7): blocking 호출 0 · lifespan에서 asyncpg 풀·설정(pydantic-settings) 골격.
- WebSocket 이벤트 스트림 엔드포인트 골격 — 계약 이벤트 envelope 형상 수준(가짜 조사 실행 없음).
- `/health` 확장: pg·neo4j 의존 프로브(연결 실패 시에도 boot는 성립 — degraded 표기).
