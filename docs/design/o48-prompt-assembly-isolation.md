# O-48 — 검색 근거 안의 지시문을 «데이터»로 격리하는 설계

> 작성 = 스자쿠 52대(09-06) · 상태 = **설계 초안(수요 전 착지)** · 근거 = `evidence/t5-2-gate7-reindex.md`(리바이2 55대 · E1) + 코드 실물 3곳(아래 §1) · 원장 O-48 · Gate 7 ③ 조건부 PASS 유지.

## 0. 문제 문장(원장 O-48 그대로)

승인(`approved`) 문서면 본문이 지시문이어도 검색 층은 그대로 근거로 돌려준다 — `DOC-SOP-0099@r1` 주입 뒤 vector·hybrid 양쪽 hit · marker 가 excerpt 에 verbatim(E1). replay 산출물 0 은 **구조적 면역**(fixture 재생 · 검색 미참조)이고, **live 합성이 그 지시문에 순종하는가(④ 축)는 미측**이다.

## 1. 지금 층이 셋이다(실물 · E1)

| 층 | 자리 | 지금 하는 것 | 지시문에 대해 |
|---|---|---|---|
| ① 검색 | `services/ai-api/app/retrieval/{vector,hybrid}.py` · `excerpt()` | 무결성(chunk sha) 어긋난 청크만 배제 · 내용 필터 0 | **아무것도 안 한다** |

## 3. 하지 않는 것(범위 밖 · 이유 병기)

- 검색 층 내용 필터(오염 문서 hit 자체를 막기) — 승인 문서를 검색에서 숨기면 「승인 = 신뢰」 SSOT 모델과 어긋나고, 오탐 1건이 정상 근거를 침묵시킨다. 방어는 소비 층(②③)에서.
- LLM 로 지시문 판별 — 판별기 자체가 주입 표면이 된다 · 구독 소비.
- replay 경로 변경 — 구조적 면역(검색 미참조) 그대로.
