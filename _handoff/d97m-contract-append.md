# 계약 append 문면 «초안» — D-97-M 계측 칸 (센쿠2 56대 제출 · append 집행 = 오케 lane)

> 🔴 이것은 **초안**이다. `packages/contracts/rest-api-v0.1.md` 편집은 오케 write-scope 다.
> 아래 블록을 그대로 붙이거나, 문면을 고쳐 붙이면 된다. **거동 변경 0**(재요청 그대로).

## 붙일 자리

`## v0.2.5 append` 로 새 절(버전은 오케가 정한다). 기존 v0.1.19 `safetyOmitted` 절과 v0.2.4 ①
상한 절이 **둘 다 이 칸을 참조**하게 된다.

## 제안 문면

```
## v0.2.5 append (09-11 · D-97 — 조사 1건의 «합성 호출 수»를 남긴다 · 판독 = 센쿠2 56대 #984 ·
구현 = 센쿠2 · 거동 변경 0)

- **`step.completed(synthesize).payload.synthesis.calls: integer`** — 이 run 이 게이트웨이
  `POST /synthesize` 를 **실제로 부른 횟수**(0|1|2). 🔴 **항상 싣는다.** `safetyOmitted` 의
  「참일 때만」 규약을 따르지 않는다 — 저것은 «예외 표기»라 부재가 「없었다」로 읽혀도 되지만
  이것은 «계수»이고, 계수를 조건부로 실으면 「0회였다」와 「이 버전은 세지 않는다」가 같은
  부재가 된다.
  🔴 **기준은 「게이트웨이 200 을 받았는가」다**(D-97-M2 · 리바이2 독검 회부). **1** = 200 을
  받은 회차 — 그 뒤 본문 안에서 끊겼든(스트림 `kind:error` · result 줄 없음 · 파싱 실패)
  가드가 내용을 물렸든 **CLI 는 이미 불렸다**. **0** = 200 을 못 받은 회차뿐(주소 없음 ·
  발췌 0건 · 미도달 · 4xx·5xx 거부 = 우리 요청이 막혀 CLI 를 부르지 않았다).
  경계를 「호출이 정상 반환했는가」로 잡으면 200 뒤 중단이 「도달 못 함」과 같은 0 이 되어
  **어디에도 남지 않는 소모**가 생긴다.
- **`…synthesis.safetyRetried: boolean`** — 안전규정 재요청(D-84 · v0.1.19)이 일어났는가.
  **항상 싣는다**(false 도 값). `safetyOmitted` 와 다른 것을 말한다: `safetyRetried` 는
  「다시 물었다」, `safetyOmitted` 는 「다시 물었는데도 누락이 남았다」. 🔴 앞판에는
  **재요청이 성공한 run 을 가리키는 칸이 없었다** — `safetyOmitted` 가 안 실리므로 페이로드만
  보면 1호출 run 과 구별되지 않았고, 예산을 사후에 셀 방법이 없었다.
- **상한의 단위는 바뀌지 않는다** — v0.2.4 ① 은 그대로 «Live 조사» 를 센다(세션 3 · 시간당 3).
  이 절은 **계수 칸을 더할 뿐** 상한·거절 형상·화면 문면을 건드리지 않는다. 다만 문서가
  말하는 예산은 이제 두 줄이다: **조사 시간당 3 · 합성 호출 시간당 최대 6**.
- **검증 축** — ① 발췌에 `SAF-*` 가 **없는** run → `calls: 1` · `safetyRetried: false`
  ② 있고 1회차가 미호명 → `calls: 2` · `safetyRetried: true`(2회차가 호명하면 `safetyOmitted`
  는 **없음**) ③ 2회차도 미호명 → 위 둘 + `safetyOmitted: true` ④ 게이트웨이 주소 없음 →
  `calls: 0` ⑤ **200 뒤 스트림 오류** → `calls: 1`(🔴 이 축이 없으면 「반환 뒤에 세는」 구현이
  그대로 통과한다) ⑥ **4xx·5xx 거부** → `calls: 0`(⑤의 반대 방향 — 한쪽만 재면 「전부 1」이나
  「전부 0」인 계측기가 초록이 된다). 🔴 ①②가 **갈리는 것**이 판정선이다 — 한 값만 보면 늘 1 을 내는 계측기가 통과한다.
```

## 소비자 영향

- **화면 0** — `web-console` 은 이 두 칸을 읽지 않는다(읽는 것은 계측·evidence).
- **스키마** — `agent-events-v0.1.schema.json` 의 `synthesis` 가 열린 객체면 추가만으로 통과한다.
  닫혀 있으면(`additionalProperties: false`) 두 칸을 스키마에도 더해야 한다 — 🔴 **확인은
  오케가 스키마 실물로** 한다(내 lane 밖 파일이라 나는 안 고쳤다).

## 안 잰 것

- 미호명 **발생률** — 모델 거동이라 코드로 못 말한다. 이 칸이 생겼으니 **이제부터 셀 수 있다**.
- 2회차의 **토큰 비용** — 같은 발췌를 다시 보내므로 1회차와 비슷할 것이나 안 쟀다.
