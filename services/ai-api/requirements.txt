# 🔴 D-17 (2026-09-02) — starlette 를 «직접» 핀한다. 전이 의존이라 requirements 에 이름이
#    없었고, 그래서 0.41.3 이 PYSEC 9건(중복 접으면 7건)을 단 채로 조용히 따라 들어왔다.
#    권고들이 요구한 수정판의 «최댓값»이 1.3.1 이다(PYSEC-2026-249) — 그 아래는 일부만 덮는다.
#
#    🔴 fastapi 가 0.115.6 → 0.133.0 으로 «함께» 오른 이유는 최신이라서가 아니다:
#       fastapi 0.115.6 의 메타데이터는 `Requires-Dist: starlette<0.42.0,>=0.40.0` 이라
#       starlette 1.3.1 을 **핀만으로는 못 올린다**(해결기가 충돌로 거절한다). PyPI 메타데이터를
#       0.115.7 부터 순서대로 실측한 결과, 상한이 사라져(`starlette>=0.40.0`) 1.3.1 을 허용하는
#       **최초 버전이 0.133.0** 이다(0.132.1 까지는 `<1.0.0`). 즉 «허용하는 최소 버전»이지
#       「최신 추종」이 아니다.
#
#    🔴 이제 starlette 의 상한은 fastapi 가 아니라 **이 핀**이 쥔다 — fastapi 가 상한을 놓은
#       이상, 여기서 == 로 고정하지 않으면 다음 설치가 조용히 다른 starlette 를 끌어온다.
