# synthesis-gateway 런타임 의존 = 0.
#
# 표준 라이브러리(http.server · subprocess · json · tempfile)만 쓴다. 이 파일은 「무엇을
# 안 들였는가」를 남기려고 둔다 — 다른 서비스(ai-api·indexer·projector)는 requirements.txt
# 를 갖는데 여기만 없으면 「빠뜨린 것」과 「필요 없는 것」이 같은 모양이 된다.
#
# 왜 프레임워크(FastAPI/uvicorn)를 안 들이는가:
#   - 이 프로세스는 운영자 PC 에서 실측·녹화 때만 잠깐 뜨고 내려간다(상시 가동 0).
#   - 라우트 2개(POST /synthesize · GET /health) · 동시 1 — 단일 스레드 HTTPServer 로 족하고,
#     「동시 1」이 서버 구조 자체로 보장된다(세마포어를 따로 두지 않는다).
#   - 컨테이너에 들어가지 않으므로 이미지 크기·CVE 표면을 늘릴 이유가 없다.
#
# 실행에 필요한 것은 패키지가 아니라 호스트에 로그인된 Claude Code CLI 다(env SYNTHESIS_CLI_BIN).
