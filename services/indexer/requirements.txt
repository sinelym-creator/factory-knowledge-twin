# indexer 의존 — 버전은 Python 3.14 wheel 실측으로 고정한다(소스 빌드 0 · asyncpg 0.31.0 선례).
#
# 무엇을 위해 들이는가:
#   tokenizers   : chunk 경계를 «토큰 오프셋»으로 정확히 얻기 위해. 분할은 문자 좌표에서
#                  일어나지만 예산은 토큰이라, 둘의 대응이 없으면 크기가 추정으로 떨어진다.
#   transformers : `Tokenizer.from_pretrained`가 참조하는 모델 설정(max_length·truncation)을
#                  같은 소스에서 받기 위해.
#   tiktoken     : 대조 계수기. 토크나이저가 바뀌면 chunk 좌표가 얼마나 흔들리는지를 보이는
#                  용도이지, 임베딩 후보가 아니다.
#
# 게이트 ③ 택일분 (오케 승인 2026-08-29 — 근거는 README「게이트 ③」):
#   sentence-transformers : 임베딩 런타임. fastembed는 512 token을 담는 다국어 모델이
#                  e5-large(1024dim·2.24GB)뿐이라 동결 정책과 구조적으로 충돌한다.
#   torch        : sentence-transformers의 실행 백엔드(직접 부르지는 않는다).
#
# 게이트 ④ 적재분:
#   psycopg      : pgvector 적재·조회용 동기 드라이버. ai-api는 asyncpg를 쓰지만 이쪽은
#                  «배치 스크립트»라 async 런타임을 세울 이유가 없다. [binary]로 받아
#                  libpq 빌드 도구 없이 설치된다(3.3.4 = cp314 wheel 실측).
#   fastembed    : 🔴 «게이트 ③ 재현 전용»이다 — 탈락한 후보를 다시 재기 위해 남긴다.
#                  빌드 경로(build_index.py)는 이것을 부르지 않는다. 빼면 probe_embedding.py의
#                  대조 열이 ImportError 한 줄로 바뀌어, 택일 근거를 재현할 수 없게 된다.
