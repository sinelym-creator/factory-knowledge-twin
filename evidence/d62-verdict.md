## 3. 자수 (내 계측기 — 이 티켓에서 셋)

1. 🔴 **「클릭 → 열림」을 처음엔 «열려 있는 화면»에서 쟀다.** 첫 방문이라 인트로가 이미 떠 있어
   `before=1 → after=1` 인데도 `opened:true` 가 나왔다. **닫아서 0 을 만든 뒤 0→1 전이**로 고쳤다.
2. 🔴 **닫기 손잡이를 지어냈다** — `Escape` 로 닫힐 것이라 가정했으나 안 닫혔다(`closedFirst:false` 가 그 증거).
   화면이 실제로 쓰는 `aria-label="안내 닫기"` 로 바꿨다.
3. 🔴 **고정 대기 900ms 가 「안 열림」을 만들었다** — 같은 조건 3회에서 1440 폭이 false/false/true 로 갈렸다.
   `waitFor` + **열림 지연을 값으로 기록**하도록 고쳤다.

## 4. 안 잰 것 (이름으로)

1. **1440 폭의 클릭 → 열림** — 5초 창에서도 안 열리는 회차가 있다(대상 2/2, 대조군 1/2). **대상·대조군 공통**이라
   D-62 처방과 무관하지만, **원인은 이 회차에서 못 밝혔다**(내 그물의 닫기→재열기 순서일 수도, 화면의 축일 수도).
   ⇒ **별건 관측**으로 남긴다. 390(발주 축)에서는 양쪽 다 안정적으로 열린다.
2. **키보드 도달·포커스 링** — 코드에 `fkt-hit` 는 있으나 눌러 보지 않았다.
3. **게이트웨이 도달 무대에서의 `shell.spec.ts` 9/9** — 위 2 절의 전제를 만족하는 무대를 세우지 못했다.
4. **스크린리더 실측** — `sr-only` 제거가 「두 번 읽힘」을 없앴는지는 보조기술로 확인하지 않았다(구조로만 확인).
