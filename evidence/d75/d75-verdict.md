## 5. 🔴 자수 — 내 계측기가 만든 가짜 빨강 2건 (대상 결함 아님)

1. **1차 회차: 「조사 시작」 0건 → `exit 2`.** 고정 대기 1.5s 로 물었다. 이 버튼은 «알람 목록 안»에 있고
   그 데이터는 브라우저가 직접 부르며, 세션이 API 로 발급되기 전에는 `disabled` 다. **cap 소모 0**으로
   막혔다(안전장치가 설계대로 섰다). 처방 = `:not([disabled])` + `waitFor(visible, 45s)`.
2. **2차 회차: `mode=null` 때문에 `STAGE_NOT_RANG`.** `GET /runs/{id}` 응답에 **`mode` 키가 없다**
   (실측 키 = `status`·`candidates`·`workOrderDraftId`). **없는 키를 O-16 배제 축으로 삼았다.** 무대는
   실제로 울렸는데 내 판정 규칙이 「안 울림」이라 답했다. 처방 = 접두 일치(`prefixMatch`)를 축으로 —
   재생본이면 GP id 가 «녹화 run» 접미를 갖기 때문이다. **이 자수는 값을 바꾸지 않는다**: 측정값
   (200/200/200 · 5건)은 그대로이고, 바뀐 것은 «울림 판정 규칙»뿐이라 원 JSON 을 재실행 없이 손판정했다.
