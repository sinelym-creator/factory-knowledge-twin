## 1. 축① — 실무대 exit 7 (내 재계수)

### 1-a. 로그 직독

```
document_chunk = 0 (색인 전이라 0 이어야 한다)
측정 모델: ci:github-actions run 34007547065
표본 10문 …
JSON -> /tmp/ctrl.json                      ← 🔴 «빨강인데» 산출물이 써졌다(O-54 ⓐ)
구조 가드 FAIL: 전 호출 503 index_unavailable · hit 0 — 검색이 죽은 게 아니라 «색인이 없다»(서버가 부재를 이름으로 말했다)
대조군 rc=7 (기대 7 = 색인 없음)
--out 실재 · rows 10 · status [503] · code ['index_unavailable']
```

### 1-b. artifact 재계수 — 발주문·센쿠2 값은 전언, 아래는 내가 센 값

`/tmp/ctrl.json` 을 내려받아 **행에서 직접** 셌다(스텝이 출력한 요약 줄을 읽지 않았다):

| 값 | 내 재계수 |
|---|---|
| rows / calls | **10 / 20** |
| status 분포 | **`{503: 20}`** · 200 = **0건** |
| code 분포 | **`{index_unavailable: 20}`** |
| `nonOk.absenceVerdict` | **true** |
| `firstRaw` | `{"error":{"code":"index_unavailable","message":"document_chunk 에 임베딩이 0건이다 — 색인(T1-4)을 먼저 확인하라"}}` |
| `model` | `ci:github-actions run 34007547065`(= 그 run 의 실제 id) |
| 교정 | 없는 code(`no_such_code`)로 세면 **0** |

→ **드릴(스텁)에서만 서 있던 `exit 7` 이 실무대에서 섰다. E2 → E1 승격.** 앞 판정문(`o54-runner-exit-split.md` §4-5)에 「안 본 축」으로 남긴 자리가 닫혔다.

🔴 **`--out` 이 빨강에서 실재한 것이 O-54 ⓐ 의 실증이다.** 앞판이었다면 이 국면에서 파일이 없었고, `index_unavailable` 을 알아내는 데 또 두 run 이 들었을 것이다.

### 2-b. 🔴 「exit 7 이 나면 안 되는 자리」 — 같은 run 안의 음성 대조군

| 열 | 상태 | `nonOk.absenceVerdict` | rc |
|---|---|---|---|
| 前(색인 0) | 503 × 20 | **true** | **7** |
| 後(색인 있음) | **200 × 20** | **false** | **0** |

같은 문이, 같은 무대에서, 같은 실행 안에서 **한 번은 「색인 없음」이라 말하고 한 번은 말하지 않았다.** 이것이 없으면 「무엇이든 7 로 보내는 문」도 이 초록을 냈을 것이다. (스텁 드릴의 ⑤⑥열이 코드 축에서 같은 질문을 물었고, 이 표는 그 질문의 **실무대 판**이다.)

## 4. 🔴 안 본 축 (이름으로)

1. **`--gate`(exit 10)** — 이 회로에 없다(#852 별건).
2. **exit 5 의 실무대 판** — 색인이 있는데 200 위에서 hit 0 이 되는 무대는 이 run 에 없다. 그 갈래는 여전히 **스텁 드릴에서만** 섰다(드릴 ②열).
3. **부재가 아닌 5xx·상태코드 섞임의 실무대 판** — 같은 이유로 드릴에서만(⑤⑥열).
4. **graphrag·Windows·live 합성** — 회로 밖(neo4j `unconfigured`).
5. **프로브 제거의 회귀** — 그 계측기가 잡던 축을 러너가 «전부» 대신하는지는 이 run 하나로 말할 수 없다. 이 run 에서는 러너가 status·code·원문을 다 실었다는 사실까지가 값이다.

## 5. 자수

1. **이 판정은 내 코드를 내가 검증한 것이다.** §2-b 를 넣은 이유가 그것이고, 그럼에도 「내가 짠 문을 내가 고른 열로 시험했다」는 편향은 남는다 — 다른 좌석이 같은 축을 다시 물으면 그 값이 이 문서보다 세다.
