## §6 ③ 쿠키 축 — 「서버 세션을 만들지도 위조하지도 않는다」 = **PASS**

그물 = `tests/web/t42a_static_cookie_probe.mjs` · 🔴 **세 갈래로 갈라** 잰다(§0 자수 2 참조).

| 갈래 | 쿠키 실측 |
|---|---|
| ⓐ **딥링크**(`/` 무경유 · 정적 URL 직행) | **0건** — `fkt_session`·`fkt_sid` 둘 다 없다 |
| ⓑ **입장 경유**(`/` → 제안 → 정적) | 제안 «전» `fkt_session=pending:<uuid>` → 정적 진입 «후» **동일**(새 쿠키 **0건 추가**) · `fkt_sid` **끝내 없음** |
| ⓒ **LIVE 대조군** | `fkt_sid=<sid>` **실재** + `fkt_session=api:<sid>` |

🔴 **위조 0 의 실증**은 값의 «접두»에 있다: OFF `pending:` ↔ LIVE `api:`.
셸 쿠키가 자기 origin 을 스스로 말하므로, 정적 방문자가 서버 눈에 「있는 세션」인 척하지 않는다.
그리고 ⓑ 의 `fkt_session` 은 **`/` 의 입장 시도**가 남긴 것이지 정적 경로가 만든 것이 아니다 —
ⓐ 가 그것을 갈랐다.

| 무엇 | 실측 |
|---|---|
| 방문자 상태 | `localStorage["fkt.static-replay.visitor"]` = `{visitorId, cursor, visits…}`(§14.1 그대로) |
| R-1 「세 번째 origin `static`」 | **쿠키가 아니라 별 표지**로 산다 — `static-visitor-chip[data-origin="static"]`(`lib/session.ts` 는 `api`·`pending` 만 파싱). 쿠키 이름을 빌리지 않으려는 설계가 코드 주석과 실물에서 일치 |
