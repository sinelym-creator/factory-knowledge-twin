## 3. ㉗ `bootstrap.ps1` 이 DSN 을 «준다» — 줄 실물

```powershell
# 🔴 색인·투영은 «호스트»에서 돌고 컨테이너 밖에서 DB 를 본다 — 그래서 대상을 명시해야 한다.
#    D-72 이후 두 스크립트는 «기본값을 갖지 않는다»: 안 주면 색인하지 않고 rc 2 로 죽는다.
#    그전에는 조용히 기본 포트 5434(= «다른 스택»)를 갈아 치울 수 있었다.
$env:FKT_POSTGRES_DSN = "host=127.0.0.1 port=$PostgresPort user=fkt password=fkt_local_dev dbname=fkt"
# PG* 는 psql·마이그레이션 등 «libpq 를 직접 쓰는» 자리를 위해 남긴다 — 색인·투영은 위 DSN 만 본다.
```

⇒ 부트스트랩 경로는 **끊기지 않는다**(스크립트가 엄격해졌는데 자동 경로가 값을 못 주면 그게 회귀다).
PG* 를 남긴 이유도 그 줄이 스스로 말한다.

## 4. 🔴 안 잰 것 · 자수

1. **`services/projector/verify_projection.py` = 안 잼.** 이 리포에서 DSN 을 쓰는 스크립트는 **3본이 아니라 4본**이다
   (`verify_*` 둘이 `build_*` 의 `dsn_from_env` 를 import 한다). 그런데 이 1본은 **양쪽 트리 모두 rc 1** 이었고,
   원인은 **내 계측기**였다 — `neo4j` 모듈이 없는 **indexer venv** 로 돌렸다(`ModuleNotFoundError: No module named 'neo4j'`).
   DSN 갈래에 닿기 «전»에 죽었으므로 **이 축에 대해 아무 말도 하지 않는다.** projector venv 로 재실행하면 값이 난다.
2. **발주문의 「3 스크립트」는 실물과 다르다** — 위 4본. 셋은 실측 PASS, 넷째는 안 잼.
3. **`--dsn` 오타·잘못된 대상**은 안 쟀다(예: 존재하는 다른 DB 를 주면 그대로 간다 — 처방은 «명시 강제»지 «대상 검증»이 아니다).
4. **동시 실행·권한 없는 DSN** 축 안 쟀다.
5. 대조군 rc 124 는 **내 20초 시한**의 값이다 — 「영원히 안 끝난다」가 아니라 「20초 안에 안 끝났다」가 실측이다.
