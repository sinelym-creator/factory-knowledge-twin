# T7-8a — WCAG 2.5.8 / 2.5.5 폭 축 전개

**판정: 🔴 **AA(2.5.8) 위반 0 — 36칸 전수.** 「교차가 처음 생기는 폭」은 **없다**(390px 까지 내려가도).
⇒ T7-4 가 남긴 유보 **「이번 초록은 1440 의 초록이다」가 이 축에서 «닫혔다».**

- 좌석: 리바이2 36대(검증) · 2026-09-04 · 근거 등급 **E1(실측)**
- 무대 = **`fb1a0c5`**(측정 시점 develop tip · PR#512 병합분) · `:3115`
- 잰 것 = **폭 6열 × pointer 2열 × 3화면 = 36칸** · chromium 1벌 · prod 1벌

---

## 0. 판정선 = SC 원문(T7-4 와 동일 · `evidence/t74-target-size-baseline.md` §0 참조)

**2.5.8(AA)** 24×24 + **Spacing 예외** · **2.5.5(AAA)** 44×44 · 예외 없음 · **퍼센트 문턱은 SC 에 없다.**
🔴 기계가 판정하는 예외는 **Spacing 하나뿐**이라 이 그물의 빨강은 **「AA 위반 후보」**다(이번엔 0건).

## 1. 결과

`대상 / 24미만 / AAA 통과` (3화면 합계 · AA 위반 후보는 **모든 칸 0**)

| 폭 | pointer **fine** | pointer **coarse** |
|---|---|---|
| **390** | 61 / 22 / **2** | 65 / 19 / **17** |
| **768** | 65 / 23 / **0** | 65 / 20 / **22** |
| **1024** | 65 / 23 / **0** | 65 / 20 / **28** |
| **1280** | 65 / 23 / **1** | 65 / 20 / **26** |
| **1440** | 65 / 23 / **0** | 65 / 20 / **27** |
| **1920** | 65 / 23 / **0** | 65 / 20 / **27** |

- 🔴 **AA 통과 = 36/36 칸 전수.** 24 미만 대상(칸마다 19~23개)이 **전부 Spacing 예외로 통과**한다 —
  어느 폭에서도 24px 원이 다른 대상·다른 미달 원과 **한 건도 교차하지 않는다.**
- 🔴 **「깨지는 폭」이 없다** = 이 화면들의 간격이 **390px 까지 24px 여유를 지킨다.**
  T7-4 의 유보(「1440 의 초록」)는 **이 축에서만** 닫혔다 — 아래 §4 의 미측 열은 그대로 남는다.
- **AAA 는 pointer 가 가른다** — fine 0~2 vs coarse 17~28. `.fkt-hit::before` 확장이
  `@media (pointer: coarse)` 안에만 살기 때문이고, **fine 열에 44 자를 맞출 장치는 없다**(설계).

### 🔴 관찰 1 — fine 390px 에서 대상이 **61개**(다른 칸은 65)

레일이 접히고 바가 뜨는 자리다(D-41). 가시성 필터가 **숨은 쪽 4개를 버렸다.**
🔴 **coarse 390px 은 65개**로 갈린다 — pointer 조건이 레이아웃(히트 확장 높이)을 바꿔 접힘이
달라지기 때문으로 «보이지만», **그 인과는 안 쟀다**(E4 가설 · 개수 차이만 사실이다).

### 관찰 2 — fine 1280px 만 AAA 1

작은 수의 흔들림이다. **판정에 안 썼다** — 36대가 step3 에서 세운 규율대로 **흔들리는 계수는
헤드라인으로 쓰지 않는다.**

## 2. 🔴 D-41 — 「같은 이름의 두 대상」을 버리는 장치

폭이 줄면 레일이 접히고 바가 뜨는데 **`data-testid` 가 양쪽에 같다.** 숨은 쪽을 집으면
**두 대상이 서로의 24px 원을 교차시켜 «없는 위반»을 만든다.**
⇒ `checkVisibility({checkOpacity, checkVisibilityCSS, contentVisibilityAuto})`(+ `offsetParent` 폴백)로
보이는 것만 남긴다. 그 효과가 §1 관찰 1(61 vs 65)에 그대로 보인다.

## 3. 🔴 대조군 — 「대조군도 늙는다」를 스스로 적용했다

T7-6 에서 **처방이 음성 대조군의 전제를 죽인** 일을 겪었다. 여기서는 **폭이 전제를 죽인다** —
T7-4 는 통과-보장 버튼을 **(1200, 700) 고정 좌표**에 심었는데, **390px 뷰포트에서는 화면 밖**이다.

⇒ 대조군을 **뷰포트 상대**로 심고, **폭×pointer 12벌 전부에서 다시 세웠다**:

| 대조군 | 심은 것 | 판정선 | 결과 |
|---|---|---|---|
| ① 위반 보장 | 12×12 두 개 · 중심 간 18px · **뷰포트 중앙** | AA **위반** | **12/12 벌 위반 검출** |
| ② 통과 보장 | 60×60 · **`(w−80, h−80)`** | AA·AAA **통과** | **12/12 벌 통과** |

🔴 그리고 **「모집단에 있는지」를 먼저 본다** — 심은 요소가 스캔 결과에 **없으면**(화면 밖 등)
`exit 2` 로 죽인다(`대조군② 소실 — 화면 밖 = 전제 죽음`). **전제가 죽은 회차를 초록으로 넘기지 않는다.**

## 5. 🔴 이 측정이 사람보다 유리 / 불리한 점

- **유리** — 36칸 × 61~65 대상의 **경계와 실제 눌리는 상자**를 소수점까지 전수로 읽는다.
  사람은 폭을 6번 바꿔 가며 65개를 눌러 보지 않는다.
- **불리** — 🔴 **무엇이 «하나의 대상»인지 사람처럼 못 가른다.** 시각적으로 한 덩어리인 것을 둘로
  세면 원 교차가 늘고, 반대면 줄어든다. 또 **`checkVisibility` 가 참이라고 사람 눈에 보이는 것은
  아니다** — 화면 밖으로 밀린 것, 다른 것에 덮인 것은 이 필터가 못 가른다.
