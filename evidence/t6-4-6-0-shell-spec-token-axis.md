# T6-4 ⑥-0 — `shell.spec.ts` 앱바 색 판정축을 **토큰 계산값**으로 전환 · E1

## 무엇이 문제였나

`tests/web/e2e/shell.spec.ts` 의 「V-2 대조군」 행이 앱바 배경을 **리터럴** `rgb(17, 24, 35)` 로
고정하고 있었다. 그 행은 「토큰 계층이 살아 있다」를 재려던 자리인데, 실제로는 «이 팔레트의
이 값»을 재고 있었다 — 팔레트를 갈면 **설계대로 바뀐 화면이 빨강**이 된다(T6-4 PR 1 #442).

## 바뀐 판정축

앱바 `backgroundColor` ∈ { 런타임에 **실제로 풀리는** 표면 토큰의 계산값 } —
후보 = `--fkt-bg-2` · `--fkt-glass` · `--color-panel`(별칭). 선언이 없는 토큰은 **허용 집합에
넣지 않는다**(없는 토큰을 통과 사유로 쓰지 않기 위해서다). 집합이 비면 초록도 빨강도 아닌
**측정 불가**로 세운다.
