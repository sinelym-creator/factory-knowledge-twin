인데 거기에 `sessionId` 를 실어서, 소유권을 따지기 «전»에 422 가 먼저 섰다. 본문에 자리가

가려졌던 «참»이다.

## 2. 🔴 V-1 — ai-api 세션 쿠키가 브라우저까지 오지 않았다 (적발 → 픽스 → 재검 green)

발주가 얹은 **+축**(구현이 못 잰 것 = `next build` 실구동)에서 나왔다. 구현 좌석은 워크트리에
`node_modules` 가 없어 tsc/eslint 만 clean 이었고, 「빌드된다」는 미검이었다.
빌드는 실제로 섰고(rc=0 · 6라우트 + Proxy Middleware), 결함은 **그 다음 칸**에 있었다.

| 측정(적발 시 · 전부 독립) | 결과 |
|---|---|
| curl 원 헤더 — `/` 진입 | **set-cookie 1개** · 그 하나는 표시용 `fkt_session` · `fkt_sid` 없음 |
| playwright 브라우저 컨텍스트 | `fkt_session`(httpOnly=false) 하나뿐 |
| 브라우저 경유 `GET /api/scenarios` | **401** |
| 🔴 대조군 | 셸이 쥔 id 를 `fkt_sid` 로 직접 → **200** · 지어낸 id → **401** |

→ 발급·다리는 성립하고 **브라우저 전달만** 끊겼다. `proxy.ts` 자기 주석이 막겠다고 적은 상태다.

**재검(픽스 0628201 · E1)** — 🔴 셸을 **다시 빌드**하고 쟀다. `proxy.ts` 가 바뀌었으므로 옛
`.next` 로 재면 픽스가 아니라 옛 빌드를 검증한다(서버 쪽에서 겪은 계보 ⑦ 의 셸 판(版)).

| 재검 | 결과 |
|---|---|
| curl 원 헤더 | **set-cookie 2개** — `fkt_sid`(**HttpOnly**) + `fkt_session` |
| E-1 브라우저 축 | **PASS** — 브라우저가 `fkt_sid` 를 쥐고, 브라우저 경유 `/api/scenarios` **200** |
| 대조군 | 진짜 id 200 / 지어낸 id 401 — 「200 의 주어는 쿠키다」 유지 |

🔴 **완료 기준이 사람이 아니라 코드였다.** E-1 축이 이 red 를 상시로 들고 있었고, 픽스는 그
축 위에서 green 이 됐다 — 「고쳤다」의 주어가 구현 좌석의 말이 아니라 검증 좌석의 그물이다.

🔴 **재검에서 내 계측기가 한 번 더 거짓말했다.** 셸 재기동이 `EADDRINUSE` 로 실패했는데
포트는 **옛 프로세스**가 물고 있어 응답했다 — 그 상태로 잰 첫 재검은 「픽스가 안 먹었다」로
보였다. 프로세스를 확인하고 정리한 뒤 다시 쟀다. 이 대에서 세 번째다(§5).

세 번째 실물이고, 이번에는 그 낡음이 «무리로» 온다는 것까지 보였다.

### 3.1 🔴 E-05 — 세 번째 죽음에서 «형태»를 바꿨다

표본을 두 번 갈았다. `POST /api/sessions`(T3-1 이 구현) → `GET /api/plants`(T3-2 가 구현).
**한 시간 안에 두 번 죽었다.** 세 번째 교체 후보를 받았을 때, 갈아 끼우는 대신 물었다 —
이 칸이 재려는 것이 무엇인가.

「그 경로가 501 인가」가 아니라 **「501 도 계약 형상인가」**다. 경로는 표본이지 축이 아니다.
그래서 **지금 501 을 내는 라우트를 계약 표면에서 «찾아» 쓴다**(`find_unimplemented()`).
하나도 없으면 그 칸은 **측정 불가로 건너뛰고 분모에서 뺀다** — 없는 표본 위에서 초록을
만들지 않는다.

🔴 이것이 §3 의 ⑥⑦⑧과 같은 병의 «구조적» 처방이다. 낡는 표본을 갈아 끼우는 것은 그때뿐이고,
**표본을 이름이 아니라 조건으로 잡으면 낡지 않는다.**

## 4. E-2~E-6 — 관문을 옮겼다 (정직성 테스트가 «거짓 채근»을 했다)

앞판은 E-2~E-6 을 「브라우저 데이터 경로가 401」이라는 조건에 묶어 뒀다. V-1 이 고쳐지자
그 조건이 풀렸고 정직성 테스트가 **채우라고 울렸다** — 설계대로다. 그런데 채우러 가 보니

🔴 **내 조건이 «틀린 관문»을 가리키고 있었다.** 이 축들의 관문은 데이터 «경로»가 아니라
**화면이 데이터를 그리는가**다. 관문을 화면별로 다시 묶었다 — T3-2~T3-5 가 한 화면씩 착지할
때 그 화면의 축만 정확히 깨어난다.
