| 행 | 무엇 | 실측 |

| C-04 | message 가 **Replay 안내** | 「지금은 Live 조사를 시작할 자리가 없다 — 잠시 후 다시 시도하거나 **Replay** 로 같은 조사를 볼 수 있다」 |
| C-05 | 🔴 큐 진입 = **오류 아님** | 200 + `run.queued` **2건** |
| C-06 | payload 형상 | `position` ≥1 · `estimatedWaitSec` = 정수 또는 null |

| C-09 | 슬롯이 나면 `run.started` | 받아들인 3건 전부 시작 |
| C-11 | 🔴 큐 대기 상한 초과 | `run.failed` + **`fallback:"replay"`**(사유 `live_queue_timeout`) |

계약이 정수와 null 둘 «다» 허용하므로 한 갈래만 보고 형상을 확정하지 않는다.
