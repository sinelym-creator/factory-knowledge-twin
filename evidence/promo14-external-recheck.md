## 2. ⓐ — 링크는 그린다 · 본문 축은 «안 잼»

### 2.1 서버는 GP 를 냈다 (같은 세션 · 이벤트 정본)

```
live run RUN-db86dc8d8b22 · completed · 11.8s
이벤트 근거 kind = { __n: 38, record: 9, "doc-chunk": 5, "graph-path": 5 }
```

🔴 **다른 세션으로 물으면 빈 배열이 와서 «없다»처럼 보인다** — 그래서 **같은 세션 안에서** 물었다.

### 2.2 그런데 그 run 의 화면에는 GP 링크가 0 이었다 — **주어는 내 자극이다**

`a[href*="/evidence/GP-"]` = **0**. 여기서 멈췄으면 「공개면 화면 결함」으로 회부했을 것이다.
한 겹 더 물었다 — **replay run**(cap 미소비)으로 같은 화면을 열었다:

| 열 | 화면의 근거 링크(전체) | 그중 GP |
|---|---|---|
| **replay run** `RUN-d46e9b60b17d` | **23본** | **5본** |

⇒ **화면은 GP 링크를 그릴 줄 안다.** live 회차에서 0 이었던 것은 **내가 `fetch` 로 만든 run 이라
화면이 그것을 «자기 조사»로 보지 않았기 때문**일 가능성이 높다(44대 유언: 화면 흐름 「조사 시작」으로 만들어야 한다).
**대상 결함으로 회부하지 않는다.**

### 2.3 본문 축은 왜 «안 잼»인가

replay 로 GP 링크를 눌러 본문을 재려 했으나:

```
GP 화면: graph-path-body=0 · 걸음 li=0 · walk 0자 · 「서버에 닿지 못했습니다」 false
```

**재생본의 GP id 는 녹화 당시 run 을 가리켜 서버가 404 를 낸다**(D-68 §a-4 = **O-16**).
즉 **replay 로는 이 축을 잴 수 없다.** 본문 축은 **live run + 화면 「조사 시작」 클릭**이 필요한데,
**live 소모 상한(≤2회)을 이미 썼다** ⇒ 다음 회차로 넘긴다.

## 3. ⓗ 캡처 — 🔴 발주가 원한 그림이 아니다

`promo14-gp-1280.png`(50.9KB)는 **replay GP 근거 화면**이고, 위 §2.3 대로 그 화면은
**본문이 없는 「찾을 수 없음」 화면**이다. 발주의 「근거 GP 화면」(경로 본문이 그려진 그림)이 **아니다**.
중계에 쓰려면 **live + 화면 흐름** 회차에서 다시 찍어야 한다. 이름으로 남긴다.
