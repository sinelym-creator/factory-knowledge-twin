## 2. ⓐ — 링크는 그린다 · 본문 축은 «안 잼»

### 2.1 서버는 GP 를 냈다 (같은 세션 · 이벤트 정본)

```
live run RUN-db86dc8d8b22 · completed · 11.8s
이벤트 근거 kind = { __n: 38, record: 9, "doc-chunk": 5, "graph-path": 5 }
```

🔴 **다른 세션으로 물으면 빈 배열이 와서 «없다»처럼 보인다** — 그래서 **같은 세션 안에서** 물었다.

### 2.2 그런데 그 run 의 화면에는 GP 링크가 0 이었다 — **주어는 내 자극이다**

`a[href*="/evidence/GP-"]` = **0**. 여기서 멈췄으면 「공개면 화면 결함」으로 회부했을 것이다.
한 겹 더 물었다 — **replay run**(cap 미소비)으로 같은 화면을 열었다:

| 열 | 화면의 근거 링크(전체) | 그중 GP |
|---|---|---|
| **replay run** `RUN-d46e9b60b17d` | **23본** | **5본** |

⇒ **화면은 GP 링크를 그릴 줄 안다.** live 회차에서 0 이었던 것은 **내가 `fetch` 로 만든 run 이라
화면이 그것을 «자기 조사»로 보지 않았기 때문**일 가능성이 높다(44대 유언: 화면 흐름 「조사 시작」으로 만들어야 한다).
**대상 결함으로 회부하지 않는다.**

### 2.3 본문 축은 왜 «안 잼»인가

replay 로 GP 링크를 눌러 본문을 재려 했으나:

```
GP 화면: graph-path-body=0 · 걸음 li=0 · walk 0자 · 「서버에 닿지 못했습니다」 false
```

**재생본의 GP id 는 녹화 당시 run 을 가리켜 서버가 404 를 낸다**(D-68 §a-4 = **O-16**).
즉 **replay 로는 이 축을 잴 수 없다.** 본문 축은 **live run + 화면 「조사 시작」 클릭**이 필요한데,
**live 소모 상한(≤2회)을 이미 썼다** ⇒ 다음 회차로 넘긴다.

### 🔴 그런데 본문이 없다 — 그리고 그건 화면 탓이 아니다

같은 GP id 를 **API 로 직접** 물어 갈랐다:

| 표면 | `GET /api/evidence/GP-412f14020051-00` (무쿠키) |
|---|---|
| **공개면**(배포 `879fc35`) | **401** |
| 로컬 **처방** `f138a5b` `:8190` | **401** |
| 로컬 **대조군** `d38f4a8` `:8191` | **404** |

**401 은 «갈래가 있다»는 표지다**(D-68 a 판정선 ③ · 갈래가 없으면 404 로 떨어진다).
⇒ **공개면에는 D-68 a 처방이 실려 있다.** 그런데 **쿠키를 가진 그 세션이 자기 run 의 GP 를 물으면 404** 다
(breadcrumb 이 「조사 RUN-412f14…」로 그 run 이 이 세션 것임을 보인다 ⇒ **소유권 문제가 아니다**).

**회부 — 유력 가설(E3, 실측 미완)**: `RunStore` 는 **프로세스 메모리**다(계약 v0.1.14 가 「워커 2+ 면 규칙이
프로세스 단위로만 선다」고 이미 경고했고, D-68 a 판정문 §a-6 은 **다중 워커를 «안 잼»으로 남겼다**).
배포에서 run 을 만든 인스턴스와 GP 를 묻는 인스턴스가 다르면 **구조적으로 404** 가 된다.
로컬(워커 1)에서 ①~⑥ 전건 PASS 였던 것과 정합한다.

🔴 **결과적으로 폐하가 본 「요청한 항목을 찾을 수 없습니다」가 승격 14 뒤에도 공개면에 남아 있다.**
문면은 옳게 고쳐졌으나(「닿지 못했습니다」 0 = D-68 b 처방 유효), **근거 자체는 여전히 안 열린다.**
**다음 대 1착 후보** — 배포 워커 수·인스턴스 수 실측(같은 세션으로 `/api/runs?sessionId=` 를 여러 번 쳐
run 목록이 흔들리는지 = 인스턴스가 갈리는지) 후 오케 회부.

## 3. ⓗ 캡처 — 🔴 발주가 원한 그림이 아니다

**두 장 다 «본문 없는 화면»이다** — `promo14-gp-body-1280.png`(live 3회째 · §2.4)는 위 404 화면이고,
`promo14-gp-1280.png`(50.9KB)는 **replay GP 근거 화면**이며, 위 §2.3 대로 그 화면은
**본문이 없는 「찾을 수 없음」 화면**이다. 발주의 「근거 GP 화면」(경로 본문이 그려진 그림)이 **아니다**.
중계에 쓰려면 **live + 화면 흐름** 회차에서 다시 찍어야 한다. 이름으로 남긴다.
