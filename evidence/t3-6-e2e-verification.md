## §3 어서션 불일치 2건 — 예산으로 설명되지 않는 쪽 (E1)

열 ①의 32 중 **타임아웃이 아닌 것은 2건**이다. 이 둘만 「화면이 무엇을 했나」를 직접 말한다.

### 3-1. 🔴 대상 사실 — `t3-4:228` WS 문구가 4404 가 아니라 1006 이다

| | |
|---|---|
| 기대(계약) | `run-note` = 「서버가 이 조사를 찾지 못했습니다」(close **4404**) |
| 실제(공개 셸) | 「실시간 스트림이 연결되어 있지 않습니다 (**코드 1006**) — 서버가 사유를 남기지 못한 종료입니다」 |
| 관측 횟수 | 18회 재조회 내내 같은 문면(잠깐 스친 값이 아니다) |

**1006** = 종료 프레임 없이 끊긴 비정상 종료다. 서버가 4404 로 «사유를 말한» 게 아니라
**연결 자체가 성립하지 못한** 모양이다. → §4 D-21.
🔴 **화면은 거짓말하지 않았다** — 끊김을 숨기지 않고 「사유를 남기지 못한 종료」라고 말한다.
이 행의 red 는 «UI 기만»이 아니라 **공개 경로의 실기능 제약**이다.

### 3-2. 회부하지 않는다 — `t3-4:342` 「무대가 사라진 자리」

「도는 조사를 멈추면 «중지됨»」이 `stopped` 대신 **`completed`** 를 받았다.
로그의 재조회 흔적: `pending` 6회 → **`completed` 57회**. 즉 **내 [중지] 자극이 닿기 전에 run 이 완주**했다.
외부 vantage 왕복이 5.59s(콜드 1회)인 조건에서 replay run 이 먼저 끝난 것이다.
⇒ **대상 결함이 아니라 「자극이 무대보다 늦었다」** — `측정 불가(무대 소멸)`로 적는다.
이 축을 정말 재려면 **더 오래 도는 run** 을 무대로 세워야 한다(다음 조각 재료).

## §4 🔴 D-21 — 공개 셸에서 WebSocket 이 서지 않는다 (E1)

### 4-1. 정본 근거 = suite 자신의 «쿠키 있는» 대조군

`t3-4:242` ⑤ WS 가드는 한 표에 두 열을 갖는다 — 무쿠키와 쿠키.

| 열 | 결과 | 읽는 법 |
|---|---|---|
| `noCookie.opened` | **false** | 가드가 막았다 — **정상** |
| `withCookie.opened` | 🔴 **false** | 유효 세션 + 실제 run 인데 **열리지 않는다** |

두 번째 줄이 D-21 의 근거다. 첫 줄만 있으면 「가드가 잘 막는다」로 끝났을 자리다 —
**대조군이 없으면 이 결함은 영원히 초록이었다.**

### 4-2. 부수 관측 (층 판정에는 못 쓴다 — 아래 4-3 자수)

| 경로 | 자극 | 결과 |
|---|---|---|
| ⓐ Vercel 경유 `wss://<공개셸>/api/ws/runs/<없는 id>` | 실 WS 클라이언트(node 22) · **무쿠키** | non-101 · 1.24s |
| ⓐ′ 같은 경로 HTTP GET | — | **404** |
| 대조군 `/api/health` | — | **200**(같은 순간·같은 vantage) |
| ⓑ Funnel 직결 `wss://<tailnet-host>:8443/api/ws/runs/<없는 id>` | 실 WS 클라이언트 · **무쿠키** | non-101 · 142ms |

### 4-3. 🔴 내 계측기 자수 — ⓐⓑ 는 층을 못 가른다

코드를 읽고 나서야 내 프로브의 뜻이 바뀌었다.

- `investigations.py:299` — WS 라우트는 **`accept()` 를 먼저** 하고 소유권을 검사한다 ⇒ 정상 경로면
  없는 run 이어도 **101 뒤 close 4404** 여야 한다.
- `session_guard.py:243` — 그런데 **핸드셰이크 단계**에서 무세션이면 `WebSocketException` 을 던진다
  ⇒ **무쿠키의 non-101 은 「가드가 제대로 막았다」와 구분되지 않는다.**
- ⇒ 내 ⓐⓑ 는 둘 다 무쿠키였다. **층 분리 근거로 쓸 수 없다.** 부수 관측으로 강등한다.
  (「막는 처방」과 「주지 않는 자극」이 같은 초록·같은 빨강을 낸다 — 계보 그대로 내가 다시 밟았다.)

### 4-4. 남은 갈래 — **층은 미결**

| 갈래 | 판정에 필요한 열 | 상태 |
|---|---|---|
| Vercel 엣지 rewrite 의 WS upgrade 미지원(D-11 「WS 만 rewrite 잔존 · 효과 미측」 자리) | Funnel 직결 + **쿠키 있는** WS 가 101 을 받으면 이 쪽 | **미측** |
| 서버·Funnel 층 | 같은 열이 non-101 이면 이 쪽 | **미측** |

**방법**: 셸에서 `fkt_sid` 발급 → 그 쿠키를 Funnel 오리진에 얹은 브라우저 컨텍스트로 WS 1회.
오리진·쿠키 도메인이 갈려 5분짜리가 아니다. **이 창에서 못 했으면 「층 미결」로 남긴다** —
모르는 것을 아는 것으로 적지 않는다.

**영향 범위**: 공개 셸의 Live/WS 계열(§17.2 스트림 · §21 ② 사람이 밟는 경로의 실시간 축 · Gate 6 일부).
🔴 **로컬에서는 초록이었다**(전언 #248 열 112/1/1) ⇒ **코드가 아니라 «경로»가 가른 것**이다.
