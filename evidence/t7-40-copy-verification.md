- 🔴 말뭉치가 1000자 미만이면 그물이 **`exit 2`** — 빈 말뭉치는 「전부 제외」와 같아서 판정이 아니다.

### 8.4 같은 실행 4열 — 검출력을 팔지 않았다는 증명

| 열 | 자극 | Actual | 뜻 |
|---|---|---:|---|
| **ⓐ** | 확장 뒤 조사 화면 전면 스캔 | 노드 301 · **판정 0** · **제외 6** | 6건이 «안 보이게» 된 게 아니라 «제외로 분류»됐다 |
| **ⓑ** | 제외 «밖»(`run-console`)에 위반 주입 | **Δ +1 (울림)** | 검출력을 팔지 않았다 |
| **ⓒ** | 제외 조상 «안» + **자료 문면** 주입 | **Δ 0 (침묵)** | 🔴 제외가 **실제로 든다** — ⓐ 의 0 이 「원래 0」이 아님 |
| **ⓒ'** | 제외 조상 «안» + **앱 문안** 주입 | **Δ +1 (울림)** | 🔴 조상이 **통째 눈감개가 아니다** |

- ⓒ 의 자료 문면은 **화면이 준 것**(ⓐ 에서 제외된 노드의 텍스트)을 그대로 썼다 — 지어내지 않았다.
- ⓑ 또는 ⓒ 가 안 섰으면 확장을 **되돌리고** 「판정력 없음」으로 적기로 했다. 셋 다 서서 **KEEP**.

### 8.6 자수 (내 계측기)

1. 🔴 **발주문의 ⓒ 를 문자 그대로 구현했으면 확장이 REVERT 로 갔다.** 「제외 영역 안에 위반 주입 → 0」은
   **셀렉터만으로 제외할 때**의 조건이다. 내 규칙은 «자리 ∧ 출처»라 **제외 영역 안이라도 앱 문안은 울린다** —
   그래서 ⓒ 를 «자리 + **자료 문면**»으로, ⓒ' 을 «자리 + **앱 문안**»으로 **두 열로 갈랐다.**
   두 열이 아니면 「제외가 든다」와 「조상이 눈감개다」를 구별할 수 없다.
2. `data/replay/**` 를 읽어 말뭉치를 만들 때 JSON 이스케이프(개행·따옴표·`\uXXXX`)를 풀지 않으면
   화면 문면과 모양이 달라 **아무것도 제외되지 않는다** — 그러면 확장이 「한 일이 없음」으로 보인다.
3. 정본 그물에 규칙을 옮겨 붙이며 개행 이스케이프가 실제 줄바꿈으로 들어가 파일 구문을 깼다.
   `node --check` 로 잡고 고쳤다(값이 나오기 «전»).
