## §2 🔴 자극 설계에서 갈린 것 — 아무 1006 이나 쓰면 이 절은 통째로 헛돈다

착지본은 **미개통과 절단을 가른다**(`run-console.tsx:230`):

```ts
const neverOpened = !opened && ev.code === 1006;
if (neverOpened) setStreamUnavailable(true);
```

- 기존 ⓕ-1·ⓕ-3 의 자극(`routeWebSocket` + `close({code:1006})`)은 **열린 뒤** 끊는 것이라
  `opened === true` → 이 갈래가 **아니다**. 그 자극으로 폴링 축을 세우면 배너가 안 뜨고,
  그 빨강은 대상이 아니라 **내 자극**의 것이 된다.
- Playwright `routeWebSocket` 은 클라이언트 핸드셰이크를 먼저 세우므로 «101 전 close»를
  만들 수 없다 — 그래서 ⓗ 는 `addInitScript` 로 **열리지 않는 소켓**을 심는다.
- 🔴 이 자극은 **내 계측기**다. 실물 자극의 판정은 §4 프로브가 따로 진다.

### 3-1. 그물이 스스로 지키는 것

- **간격 하드코딩 0** — 판정선은 화면이 밝힌 `data-interval-ms` 다. 상수를 고친 날 그물이 빨강을
  내면 그 빨강은 대상의 것이 아니다(`:157` 「박은 값 0」).
- **무대 보존**(ⓗ-2) — 이 시나리오는 수백 ms 에 끝나고, 끝나면 폴링은 **옳게** 멈춘다. 그대로
  두면 반복을 볼 창이 사라지므로 응답에서 **종단 이벤트만** 빼서 «아직 안 끝난» run 으로
  보이게 한다. 🔴 그리고 **뺀 건수를 센다** — 0이면 무대가 우연히 선 것이라 red 가 아니라 오류다.
- **부재 앞의 앵커**(ⓗ-3) — 「배너가 사라졌다」를 묻기 전에 `data-status="completed"` 를 먼저
  세운다. 안 세우면 «아직 안 그려진 것»을 «사라진 것»으로 읽는다.
- **자취로 판정**(ⓗ-3·ⓗ-4) — 「멈췄다」를 문면이 아니라 **요청 수**로 묻는다.

## §4 외부 프로브 — `tests/web/d21c_polling_probe.mjs` (신설 · 미실행)

- **자극을 주지 않는다.** 공개 셸에서는 미개통이 실물로 일어난다. 🔴 **429 는 자극하지 않는다**
  (운영값 축 · 발주 규율) — 자극하면 공개 인스턴스의 rate limit 을 **내가 소모**하는 것이고
  그것은 잰 것이 아니라 만든 것이다.
- **잰다**: ① 배너 출현 시각 + `data-interval-ms` ② `/api/runs/{id}/events` 요청 계수와 **관측
  델타 중앙값** + 첫 회 지연 ③ 종단 뒤 배너 소멸 · 종단 뒤 창(기본 8s)의 추가 조회 0 ④ 화면
  `data-applied` ↔ 서버 seq 수(중복 0·누락 0) · **대조군** = `FKT_DIRECT_BASE` 직결 1회(폴링 0).
- **붙은 곳을 근거로 남긴다** — 첫 `/overview` 응답의 엣지 헤더를 찍는다. 공개 URL 을 쳐도
  tailnet self 로 붙은 전례가 있어(19대 계보), 표지가 없으면 「공개 경로로 쟀다」고 하지 않는다.
- **exit 규약**: 0 = 잰 축 전건 기대대로 · 1 = 어긋남 · **2 = 못 잼**. 🔴 무대가 없으면(조사가
  안 열림 · 배너도 폴링도 없음 = WS 가 섰을 수 있음) **어느 색도 내지 않는다**.
