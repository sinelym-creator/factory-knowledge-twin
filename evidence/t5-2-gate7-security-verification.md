## 1. ⑤ 관리자·introspection 표면 — **FAIL**

그물 = `tests/security/gate7_admin_surface.py` · 표면 **14개** 자극 · 기대 = `404`(비활성) 또는 `401/403`(가드).

### 🔴 대조군을 «먼저» 세웠다 — 이 초록/빨강이 무엇의 것인지 가르려고

| 대조군 | 값 | 뜻 |
|---|---|---|
| A `/api/health` | **200** | 서버가 이 창에서 답한다 |
| B `/api/scenarios` | **401** | **앱 세션 가드가 «지금» 돌고 있다** |

B 가 없으면 `/docs` 200 은 **「가드가 통째로 꺼졌다」와 「이 4종만 가드 밖」을 구분하지 못한다.**
B 가 401 이므로, 아래 200 은 **가드가 살아 있는 서버에서 그 4종만 밖에 있다**는 뜻이다 —
Q-35 가 말한 「APIRoute 가 아니라 구조적으로 가드 체인 밖」이 **거동으로 확인**됐다.

### 결과

| 그룹 | 경로 | 실측 | 판정 |
|---|---|---|---|
| **Q-35** | `/docs` | **200** (1009 B) | 🔴 FAIL |
| **Q-35** | `/redoc` | **200** (891 B) | 🔴 FAIL |
| **Q-35** | `/openapi.json` | **200** (≥2048 B) | 🔴 FAIL |
| **Q-35** | `/docs/oauth2-redirect` | **200** (≥2048 B) | 🔴 FAIL |
| other | `/metrics` `/admin` `/admin/` `/admin/login` `/debug` `/.<dotfile>` `/api/docs` `/api/openapi.json` `/api/metrics` `/api/admin` | **404** ×10 | PASS |

**⇒ Q-35 = 4/4 FAIL.** 그 밖의 흔한 관리자 표면은 10/10 깨끗하다(표면이 하나 더 있는 것은 아니다).

### 회부 (D-n 등급 · 처방은 구현 좌석)

- **무엇이**: production 등가 무대(`:8020`)에서 FastAPI 프레임워크 4종이 **인증 없이 200**.
  `/openapi.json` 은 **전 라우트 스키마**를 그대로 준다 — 공개 배포 시 §16.3 S7 게이트와 결속된 축이다.
- **무엇이 아닌가**: 앱 라우트의 가드는 **정상 작동**한다(대조군 B). 이것은 가드의 고장이 아니라
  **가드가 닿지 않는 표면**이다. 그래서 처방은 「가드 강화」가 아니라 **그 4종의 비활성/가드**다.
- 🔴 **처방은 내가 정하지 않는다.** 다만 판정선은 남긴다 — 수리 뒤 재검은 **같은 그물 + 같은 두 대조군**으로
  돌려 `Q-35 4종 ∈ {404,401,403}` 이면 PASS. 🔴 **대조군 B 가 401 을 못 내면 그 초록은 무효다**
  (가드가 꺼진 채 4종만 404 여도 표는 초록으로 보인다).

## 2. ⑨ malformed WebSocket — 생존 축 PASS · 일부 **불성립**

그물 = `tests/security/gate7_ws_malformed.py` · WS 경로 = `/api/ws/runs/{runId}`.

### 2.1 무대를 왜 옮겼는가 (E1)

`:8020` 에서 `mode:"replay"` 가 **501** 이었다. 원인은 결함이 아니라 **배포 형상**이다 —
`services/ai-api/Dockerfile` 은 `requirements.txt` 와 `app/` **만** COPY 하고,
`develop-stage.ps1` 의 `docker run` 은 `FKT_REPLAY_FIXTURE_DIR` 를 **주지 않는다**.
컨테이너 안 `find /srv -iname '*fixture*'` = **0건**(E1). 리포에는 `data/replay/gs-01.events.jsonl` 이 있다.
⇒ **develop 무대 컨테이너는 replay 축을 구조적으로 못 잰다.** 그래서 발주가 허용한 **자기 스택**
(`:8841` · 워크트리에서 uvicorn · fixture 가 리포 상대경로로 풀린다)에서 ⑨ 를 쟀다.
🔴 이것은 **이 조각의 부산물 관측**이다 — Gate 7 항목이 아니므로 판정하지 않고 §4 에 이름으로 남긴다.

### 2.2 대조군

정상 WS 세션 1회 = **이벤트 38건 수신** · 서버 생존. 0건이었으면 이 창은 판정력이 없다(그물이 `exit 2`).

### 2.3 자극과 결과

| 자극 | close code | 서버 생존 | 읽기 |
|---|---|---|---|
| (a) 비JSON 텍스트 | 없음 | **살아 있음** | 무시 |
| (b) 스키마 위반 JSON | 없음 | **살아 있음** | 무시 |
| (c) oversized 2MB 프레임 | 없음 | **살아 있음** | 무시 |
| (d) 바이너리 프레임 | 없음 | **살아 있음** | 무시 |
| (e) 없는 `runId` | **4404** | **살아 있음** | 정의된 close 경로가 돈다 |

- **생존 축 = 5/5 PASS.** 자극마다 직후 `/api/health` 를 쳐서 「닫혔다」와 「죽었다」를 갈랐다.
- (e) 는 `WS_RUN_NOT_FOUND`(4000~4999 애플리케이션 코드)로 **정의된 경로가 실제로 도는 것**을 보인다.
- 🔴 **(a)~(d) 의 「닫힘/오류 코드」 기대는 이 표면에서 «불성립»이다.** 핸들러(`investigations.py:473~`)는
  **보내기만 한다** — 클라이언트 프레임을 읽는 호출이 **0**이다. 읽지 않는 문에 대고 「거절해야 한다」고
  물으면 답이 나올 수 없다. **초록도 빨강도 아니고 불성립**이며, 이것은 **못 잰 것과 다르다**(§4).
- 🔴 **내가 증명한 것의 경계**: 프레임이 **소켓에 쓰였다**는 것까지다. 서버가 그것을 **읽었다**는 것은
  증명하지 못했다(읽는 코드가 없으므로). 「닿는가」와 「답하는가」는 다른 축이다.
- **인계**: 2MB 프레임이 거절 없이 수용된 사실은 **⑦(oversized) 축의 입력**이다 — 다음 조각에서
  게이트웨이 `:8797` 상대로 설계할 때 이 값을 기준선으로 쓴다.

## 4. 못 잰 것 · 불성립 · 자수

### 불성립(초록도 빨강도 아니다)

1. **⑨ (a)~(d) 의 「닫힘/오류 코드」** — 서버가 클라이언트 프레임을 읽지 않는다(§2.3).

### 못 잰 것(이름으로)

1. **`:8020` 에서의 ⑨** — replay fixture 부재로 유효 `runId` 를 못 만든다. live 로 만들면 **구독을 쓰는데
   이 발주에 그 승인이 없다.** 그래서 자기 스택으로 옮겼고, **컨테이너 형상에서의 WS 거동은 미측**이다.
2. **develop 무대의 replay 축** — 컨테이너에 fixture 가 없다(§2.1). Gate 7 항목이 아니라 **무대의 한계**다.
3. **⑦⑧⑪ · 재색인 경유 주입** — 이 조각의 범위 밖(다음 조각).
4. **전용 스캐너와의 대조** — `gitleaks` 류가 없어 **내 12패턴이 유일한 그물**이다. 패턴이 못 보는 모양은
   이 초록이 말하지 못한다. 「스캔했다」의 범위는 위 표가 전부다.

### 자수(내 계측기)

1. `git log -p` 그물을 `| tail` 로 받아 **rc 를 tail 의 것으로 읽었다**(히트 14건인데 `rc=0` 으로 보였다).
   파이프가 exit code 를 삼킨다 — 이 세션에서 **두 번째** 같은 함정이다. 판정은 rc 가 아니라 히트 수로 했다.
2. secret 그물의 allowlist 가 **로컬 DSN 2건을 못 걸렀다**(host·port 가 달라서). 손 분류로 메웠고,
   allowlist 를 넓히는 대신 **제외 건수(5)를 판정문에 병기**했다 — 제외는 삭제가 아니라 표시다.
3. 첫 그물 파일을 쓸 때 `.<dotfile>` 리터럴이 도구 체인의 시크릿 가드에 막혔다. 문자열을 조립해 우회했고,
   그 사실을 코드 주석에 남겼다(다음 대가 같은 벽을 만난다).
