## 3. 🔴 회부 1 — `calls` 가 「200 을 받고 본문 안에서 끊긴 회차」를 세지 않는다

- **기전**: `calls += 1` 은 `_post()` 가 **정상 반환한 뒤**에 있다. 스트리밍 갈래에서 게이트웨이가 200 을 낸 뒤 본문에 `{"kind":"error"}` 를 실으면(D-24b · `_read_ndjson`) `_GatewayStreamError` 가 `_post` 를 **뚫고 나가** `except Exception` 으로 떨어진다 — 그 경로의 `LiveResult` 는 `calls=0` 이다.
- **왜 결함인가**: 계약 v0.2.5 는 0 을 「**도달하지 못한** 회차(주소 없음·발췌 0건)」로 정의한다. 이 갈래는 도달했고 200 까지 받았다. 실 게이트웨이라면 **CLI 가 이미 돌았을 수 있는 자리**이므로 구독이 탔는데 예산표에는 0 으로 남는다.
- **대조군이 이것을 결함으로 만든다**: `guardfail` 열은 같은 「200 을 받고 거절」인데 **1 을 센다**(처방이 주석으로 명시한 그 주장은 참이다). 두 열의 차이는 **실패가 상태코드로 왔는가 본문 안으로 왔는가** 뿐이다.
- **처방 후보**(판정은 오케 몫): `_post` 호출을 감싸 **응답 객체를 받은 시점**에 세거나, `_read_ndjson` 이 던지는 예외를 `_post` 안에서 받아 「호출은 갔다」를 계수에 반영한다.
- **비고**: 이 갈래는 `log.info("synthesize calls=…")` 도 남기지 않는다(그 줄은 루프 «뒤»에 있고 거절은 그 전에 return 한다). 즉 **페이로드에도 로그에도 안 남는 소모**다.

## 4. 🔴 회부 2 — README 문면이 자기 문단 안에서 갈린다

## 7. 내 계측기 자수

1. **`validator.js` 를 0바이트로 만들었다**(ⓐ 조각). 파일을 직접 열어 쓰다 인코딩 예외가 나 truncate 만 남았다 — `git checkout` 복원 후 **임시 파일 → `os.replace`** 로 바꿨다. 이후 모든 패치는 그 순서로 했다.
2. **③ 로그 축을 처음엔 「안 남는다」로 읽을 뻔했다.** 내 탐침이 로깅 레벨을 안 열어 `log.info` 가 안 찍힌 것이었다. `basicConfig(INFO)` 를 «먼저» 켠 뒤 재측했고, 前 트리를 같은 조건으로 돌려 0건인 것까지 확인해서야 갈림이 값이 됐다.
3. **첫 실행에서 stdout·stderr 를 한 파일로 합쳐** 대상의 로그가 내 JSON 을 깨뜨렸다(파싱 실패). 측정 면에 내 출력이 섞이면 판정 전에 죽는다 — 두 스트림을 갈랐다.
4. **em dash 가 cp949 콘솔을 못 넘어** 첫 탐침이 `UnicodeEncodeError` 로 죽었다. 대상이 아니라 내 출력의 죽음이다 — `reconfigure(encoding="utf-8")` 로 고쳤다.
5. **스텁 패치 한 번이 문법을 깨뜨렸다**(escape 가 실제 줄바꿈으로 들어감). `ast.parse` 로 잡았다 — 그물을 고치면 그물부터 다시 물어야 한다.
