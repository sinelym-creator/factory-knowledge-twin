> 재현되지 않은 것은 값이 아니라 **왜 재현되지 않았는지**를 남긴다.

### 4.1 🔴 이 창의 측정 조건 — D-11(엣지 간헐 502)

12:19경부터 Production 셸의 `/api/**` 가 간헐적으로 **502 `DNS_HOSTNAME_EMPTY`** 를 낸다(엣지 rewrite 층).
19대 실측(12:25~12:32 · E1): **21/48 ≈ 44%** · 리전 헤더 전건 `icn1` · **경로·메서드와 무관**하고
같은 요청이 회차마다 200↔502로 갈린다.

| 축 | 502 |
|---|---|
| `POST /api/scenarios/GS-01/runs` | 2/8 |
| `GET /api/scenarios` | 5/8 |
| `POST /api/sessions` | 4/8 |
| `GET /api/live/status` + `GET /api/scenarios` | 10/24 |

🔴 **이 축은 이 문서의 거의 모든 칸을 오염시킨다.** 브라우저가 셸 `/api` 를 부르는 그물은 응답 본문이
JSON 이 아니게 되어 그 자리에서 죽고(`"An error o…" is not valid JSON`), 배지·배너를 읽는 그물은
**기준선부터 «미연결»** 이 된다. **18대의 값은 D-11 «이전» 창의 것이다** — 지금 값과 다른 것이 정상이고,
어느 쪽도 상대를 반증하지 않는다. 두 창은 다른 조건이다.

| **1011** 비정상(자극) | 1 | **1** | 0 (한 회차 **1**) |
| **1000** 정상(대조군) | 1 | **0** | 0 |

**갈리는 것은 events 열**이다. snapshot 이 두 열 공통 1 인 것은 **세는 눈이 살아 있다**는 증거다 —
없으면 대조군의 0 은 「계측기가 죽어서 0」과 구분되지 않는다.

🔴 대조군의 근거는 관측값이 아니라 **구현의 줄**이다: 스냅샷 재조회는 닫힘 코드를 보기 «전»에 있고
(`run-console.tsx:166`), 「끝났다/끊겼다」를 가르는 줄은 그 아래 `:170` 이다. 1차 실행에서 나는
「1000 이면 전부 0」을 기대해 FAIL 을 받았고, 선을 **값이 아니라 그 줄로** 되돌렸다.

측정 조건 — 자극 전 hold **0ms**. 이 대상에서 run 은 **1초 안에 completed** 이고 끝난 run 은 재연결
대상이 아니므로(`:174`), 창을 늘리면 **무대가 사라진다**. 3회 중 2회 전건 통과 · 1회는 D-11 502 로 exit 2.
