## 3. 안 잼 · 자수

**안 잼**
1. `?sessionId=` 를 **브라우저 세션의 id 로** 재는 축 — `fkt_sid` 가 **HttpOnly** 라 `document.cookie` 로 못 읽는다(`sid:null`). 임의 id 로만 확인했다.
2. 콘솔 오류 **5건** = `wss://…/api/ws/runs/{id}` **404**(폴링 폴백). 기지 조건으로 보이나 **확인하지 않았다.**
3. 429 축(상한 도달 · `detail` 4칸) — **상한을 소모해야 재는 축**이라 공개면에서 안 잰다.
4. 창 만료(`windowSec` 3600) 실측.

**자수**
1. 「낡은 쿠키 열」을 **의도한 시점에 못 쳤다.** 오케의 「완료」 신호를 기다리는 동안 재생성이 이미 끝나 있었고,
   내가 17:57:08 에 돌린 것은 **확인 삼아** 돌린 회차였다. 결과적으로 잡혔지만 **설계된 타이밍이 아니었다.**
2. 그 때문에 §2 의 귀속이 흐려졌다 — 셸 교체 «전»에 한 번 더 쳐 두었다면 갈랐을 수 있다.
3. ai-api 로컬 대조 무대는 **오케 전용 메인 체크아웃의 venv 인터프리터**로 띄웠다.
