## 3. 자수 (내 계측기 — 넷)

1. 🔴 **세션을 «내가» 만들었다** — 1차 회차의 축 ①②④ 전부 0 이었고, 그것은 대상 결함이 아니라
   **셸 세션(`fkt_session`)과 내가 만든 API 세션(`fkt_sid`)이 다른 것**이었다. 화면 흐름으로 교체.
2. 🔴 **`sessionStorage` 를 «다른 탭»에서 쟀다** — 탭 단위 저장소라 어느 세계에서든 0 이 나와
   「안 쓴다」가 공짜 초록이 될 뻔했다. **run 을 만든 그 탭**에서 다시 쟀고, 그제서야 대조군의
   `fkt.session-runs.v1` 이 드러났다.
3. 🔴 **대조군의 축 ⑤ 열은 성립하지 않았다** — Playwright `storageState` 는 **`sessionStorage` 를 옮기지 않는다**.
   그래서 대조군의 「API 정지」 열은 애초에 목록이 0 인 상태에서 잰 것이라 **판정력이 없다**(자극 전후가 같다).
   대조군이 「기억만 남은 조사」를 그리는지는 이 회차에서 **못 잤다** — 다만 축 ②(다른 탭 0건)가
   같은 성질을 다른 방식으로 이미 보여 준다.
4. `/enter` 는 GET 이 **405** 다. 그 페이지로 진입하려던 1차 시도는 내 경로 착오였다(대상 결함 아님).

## 4. 안 잰 것 (이름으로)

1. **다른 «기기»** — 같은 브라우저의 다른 탭까지 봤다. 다른 기기·다른 브라우저 프로필은 안 봤다.
2. **`GET /runs` 가 401 을 내는 «순간»의 화면** — 재기동 뒤 화면을 봤을 뿐, D-55 자동 재입장이
   그 사이에 새 세션을 덮었는지 여부는 이 회차에서 가르지 않았다.
3. **목록 20건 초과의 화면** — 서버 상한은 T7-41a 에서 쟀고, 화면이 그것을 어떻게 그리는지는 안 봤다.
4. **키보드·보조기술** · **1440 외 폭의 회귀**.
