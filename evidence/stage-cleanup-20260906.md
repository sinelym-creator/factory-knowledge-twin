## 0. 계측 방법 (이 표가 무엇의 초록인지)

- 리스너 맵 = `psutil.net_connections(kind='inet')` 의 `LISTEN` 만 · 포트→pid.
- 프로세스 축 = pid 별 **`cwd` 직독**(명령줄은 보조) · `exe` · `cmdline` · **`environ()`**.
- 의존(역방향) = 「누가 이 포트를 보는가」를 **전 프로세스의 명령줄 «과» env 양쪽**에서 문자열 스캔.
- 🔴 **자기 계보(self + 조상 pid) 배제** · 🔴 **2.5초 간격 2표본의 교집합만 「산 것」**으로 센다.
  (내 셸이 스스로 잡혀 거짓 의존을 만든 전례가 있다.)
- 🔴 **명령줄만 봤으면 절반을 놓친다.** 웹콘솔은 런처 `cmd.exe /c set FKT_API_BASE=... && next start` 가
  포트를 명령줄에 갖지만, **실제로 도는 자식 `node` 는 그 값을 env 로만** 갖는다. env 를 안 읽으면
  「그 API 를 보는 것 없음」이라는 **거짓 초록**이 난다 — 이번에 2본이 그 자리였다.
