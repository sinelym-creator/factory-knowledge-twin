## 2. ② replay — 재생 → 되감기

| 무엇 | 실측 |
|---|---|
| 배지 | `run-mode-badge` = **replay** |
| 문구 | **「재생본 · 원 실행 관측치」** — 값은 그대로 쓰고 성격만 밝힌다 |
| 서버 events ≡ 화면 | `data-total` == 서버 수 · `data-applied` == 전량(중복·누락 0) |
| 🔴 되감기 | 커서를 seq **n** 으로 되돌리면 **근거 수·완료 단계 수가 그 접두사의 사실과 같다** · 표기 `seq n` 일치 |
| 되돌아오기 | 「지금으로」 → `data-applied` 원복 |
| 🔴 렌더 분기 0 | 코드 축 — `run-console`·`run-panels`·`run-events` 에서 `mode === "live"/"replay"` 분기 **1곳뿐**이고 그 1곳이 배지 문구다 |

> 되감기를 「버튼이 눌린다」로 재지 않았다. **상태가 그 seq 값으로 다시 만들어지는가**를
> 서버 이벤트 접두사와 대조했다 — 누적 상태에 undo 를 붙인 구현이었다면 여기서 갈린다.
