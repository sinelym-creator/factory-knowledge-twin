# 정비 전 전원 차단·잠금·표지(LOTO)

## 1. 목적

정비·점검 작업 중 설비가 예기치 않게 기동하여 발생하는 재해를 방지한다.

## 2. 적용 범위

전 사업장의 정비·점검 작업에 적용한다. 본 규정은 의무 규정이며 면제 대상이 없다.

## 3. 절차

1. 전원 차단 후 잠금·표시(LOTO) 시행 — 작업 대상 설비의 에너지원(전기·유압·공압)을 모두 식별하고 차단한다.
2. 주 차단기를 차단하고 작업자 본인의 개인 잠금장치를 체결한다.
3. 잔류 에너지(축적 압력·관성 회전·커패시터 전하)를 방출한다.
4. 무전압·무압을 계측으로 확인한다. 확인 계측 없이 무전압으로 간주하지 않는다.
5. 「정비 중 · 조작 금지」 표지를 조작부에 부착한다.
6. 작업 완료 후 작업자 본인이 잠금장치를 해제하고 표지를 제거한다.

## 4. 금지 사항

- 타인의 잠금장치를 임의로 해제하지 않는다.
- 표지만 부착하고 잠금을 생략하지 않는다.
- 교대 시 잠금 상태를 인계하는 경우 인수자가 자신의 잠금장치를 추가로 체결한 뒤 인계자가 해제한다.

## 5. 확인

확인자는 1~5단계의 완료를 작업 개시 전에 점검하고 기록한다.
